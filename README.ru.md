# PixelBot

*[English version](README.md)*

Инструмент автоматизации десктопа, написанный в 2011–2014 годах и приведённый в состояние, в котором
он собирается и работает на актуальной JDK.

Он смотрит на экран, находит на нём объекты сопоставлением пиксельных шаблонов, управляет мышью и
клавиатурой и выполняет ваши скрипты автоматизации во встроенной IDE — с подсветкой синтаксиса,
точками останова, пошаговым отладчиком и просмотрщиком журнала. Ещё в нём есть решатель капчи-пазла
из шести плиток, который оказался самой интересной частью кодовой базы.

Изначально всё это писалось для автоматизации браузерной игры. Все её данные удалены: пиксельные
шаблоны, карта, графика. Осталась машинерия, которая никогда не была привязана к конкретной игре, и
скрипты — как рабочие примеры того, что этому движку можно поручить.

## Требования

* JDK 21 или новее
* Maven 3.8 или новее

## Сборка и запуск

```bash
mvn package
```

Получается `target/pixelbot.jar` — самодостаточный исполняемый jar. Программа читает свой рабочий
каталог: `scripts/`, `elements.elz` и файл настроек. Поэтому запускать её надо из подготовленного
каталога, а не из `target/`:

```bash
mkdir -p run/scripts && cp examples/scripts/* run/scripts/ && cp examples/pixelbot.fileprefs run/
cd run && java -jar ../target/pixelbot.jar
```

В jar вшит GraalJS, на него приходится большая часть размера. Сборка примерно вдвое меньше, только с
Rhino и Nashorn:

```bash
mvn package -P '!graal'
```

## Структура

```
src/main/java/pixelbot/
    captcha/      капча из плиток: скореры, решатели, перебор
    components/   переиспользуемые Swing-виджеты, редактор, просмотрщик журнала
    elements/     пиксельные шаблоны и их хранение
    gui/          главное окно и его панели
    script/       слои parser / instantiator / scope / debugger
src/test/java/    тесты алгоритмов капчи и скриптовых бэкендов
examples/scripts/ исходные скрипты автоматизации, оставлены как примеры
docs/             документы по ссылкам выше
tools/            генератор иконок
```

## О назначении

Программа автоматизирует десктопное приложение, глядя на экран и двигая мышь. Сетевого кода в ней
нет, и ни о какой конкретной программе она ничего не знает. Допустимо ли направлять её на что-то
конкретное — вопрос между вами и тем, на что вы её направляете; многие онлайн-сервисы это запрещают
своими правилами.

Скрипты выполняются с полным доступом к хосту — в этом смысл Java- и JavaScript-бэкендов, — поэтому
запускайте только те скрипты, которые написали сами или прочитали.
